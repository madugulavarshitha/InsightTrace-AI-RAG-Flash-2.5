# InsightTrace AI (RAG – Flash 2.5)
### Document-Grounded Insights & Recommendations Engine

> **"From Documents → Verified Evidence → Insights → Recommendations → Exact Source Traceability."**

---

## ✦ System Architecture & Design Direction

InsightTrace AI transforms high-volume business documents (quarterly financial reports, supplier contracts, RMA failure logs, and customer feedback) into verified evidence, detects compounding trends across evidence, generates clear plain-language business insights, produces defensible data-driven recommendations, and makes every result traceable to its exact source passages.

### Strict Compliance
- **100% Python** (Flask Backend, In-Memory Grounding Engine, Pure Python SVG Data Visualizations)
- **100% HTML & Jinja2** (Semantic Templates, Responsive Web Shell)
- **100% CSS** (3D Perspective, Glassmorphism, Pastel Palettes, CSS Keyframe Animations)
- **Zero JavaScript** (No `.js` files, no client-side scripts, no JS charting libraries)
- **Zero JSON** (No `.json` files, native Python data structures)

## ✦ Application Pages & Routes

1. **Landing Page (`/`)**: 3D CSS Hero with floating document cards & glowing AI core, trust value strip, 8-step connected workflow, 8 core feature cards, visual storytelling section, and signature traceability graph preview.
2. **Sign In (`/signin`)**: 2-column layout with 3D CSS document intelligence artwork and glassmorphic authentication card.
3. **Sign Up (`/signup`)**: 2-column registration interface.
4. **Dashboard (`/dashboard`)**: Summary stat cards, Plotly-style pure SVG return rate trend chart, document corpus distribution, recent insights, recent recommendations, and quick ask bar.
5. **Document Upload (`/upload`)**: Drag-and-drop document upload interface with ingestion queue and status badges.
6. **Processing Pipeline (`/processing`)**: 5-stage document parsing, cleaning, chunking, and verification progress visualization.
7. **Ask Your Documents (`/ask`)**: Business query workspace with suggested prompts and structured answer experience.
8. **Verified Evidence (`/evidence`)**: Ground-truth passage library with exact citations and confidence scores.
9. **Pattern & Trend Analysis (`/patterns`)**: Cross-document correlation and anomaly detection.
10. **Business Insights (`/insights`)**: Synthesized executive findings with supporting evidence inspection.
11. **Recommendations (`/recommendations`)**: Prescriptive operational actions, cost-recovery remedies, and timelines.
12. **Source Traceability (`/traceability`)**: Complete visual decision graph connecting user queries to primary source documents.
13. **All Documents (`/documents`)**: Enterprise document library with filters for Reports, Contracts, and RMA logs.
14. **Account Settings (`/account`)**: User profile and Gemini Flash 2.5 RAG model parameters.

## ✦ How to Run Locally

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Start the Flask application
python app.py
```

Open your browser and navigate to: **http://127.0.0.1:5000**
